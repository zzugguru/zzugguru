# 아키텍처 결정 기록

팀이 합의한 중요한 결정을 이 문서에 짧게 기록합니다.

## 2026-08-06: 초기 구조

- 렌더링은 브라우저 Canvas 2D로 시작한다.
- 기능 담당자 한 명이 클라이언트부터 서버 로직과 검증까지 수직으로 책임진다.
- 단일 기능의 코드, 테스트 데이터와 재현 시나리오는 `src/features/<기능명>`에 함께 둔다.
- 빈 폴더를 미리 만들지 않으며, 여러 기능의 통합 테스트가 생길 때만 최상위 `tests`를 만든다.
- 공통화는 실제 반복이 확인된 뒤 수행하되, 보안과 데이터 무결성 규칙은 처음부터 통일한다.
- 프레임워크는 실제 필요가 확인되기 전까지 추가하지 않는다.
- 각 기능은 가능한 한 작은 모듈로 만들고 공개 타입을 명확히 한다.

새 결정은 날짜, 결정 내용, 선택 이유, 예상되는 영향을 함께 기록합니다.
