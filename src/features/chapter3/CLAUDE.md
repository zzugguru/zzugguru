# Chapter 3 (마지막 저녁) 보완 작업 지침

이 문서는 `src/features/chapter3/` 안에서 작업할 때 루트 `CLAUDE.md`에 더해 적용되는 세부 규칙이다. 루트 문서의 add-only 원칙과 워크플로가 먼저 적용되고, 이 문서는 Chapter3 고유의 맥락을 보탠다.

## 현재 구현 범위 (2026-08-10 기준)

`client/MemoryReconstructionGame.ts`가 화면 전환과 렌더링을 중앙에서 담당하며, `Screen` / `FlowState.scene` / `EpiloguePhase`가 상태 기계 역할을 한다.

구현되어 있는 흐름:

1. 연구 구역 맵 탐색 → 장치 상호작용 (`shared/mapLogic.ts`, `shared/mapAssetManifest.ts`)
2. 기억 연결 퍼즐 (`shared/gameLogic.ts`)
3. 생체 용기 각성 연출 (`awakeningStage`, `gameLogic.ts`)
4. 기억의 방에서 추억 물건 수집 + "기억의 빈틈" 대사 (`shared/collectionLogic.ts`)
5. Letting-go 퀴즈: 붙잡기/기록/놓아주기 선택 (`shared/lettingGoLogic.ts`)
6. 에필로그: 복도 → 기록보관소 → 몽타주 → 고향별 → 일지 → 크레딧 → 포스트크레딧 (`shared/epilogueLogic.ts`)

## 스토리 갭 백로그 (원작 `Story/Chapter03.md` 대비 미구현)

2026-08-10 대화에서 사용자가 다음 4개 비트를 모두 이번 보완 작업의 대상으로 확정했다. 비트 하나를 통째로 한 작업으로 잡으면 범위가 너무 크므로(하네스 가이드가 경고하는 "인벤토리 전체를 구현한다"식 나쁜 단위), 아래처럼 세로로 얇게 썬 하위 작업 단위로 나눈다. 각 하위 작업은 `CHAPTER3_BRIEF.md`의 `Developer Request` 하나에 대응할 수 있는 크기다. 체크박스는 착수 여부 표시용이며, 실제 완료 기록은 `CHAPTER3_BRIEF.md`의 `Completed Work Log`에 남긴다.

원작에서 이 네 비트는 하나의 연속된 시퀀스를 이룬다: **경고 → (기존 구현: 퍼즐/각성/수집) → 정전·변모 → 외계 가족 구출 → 식탁 인식 → (기존 구현: letting-go/에필로그)**. 기존 흐름 중간에 새 장면을 삽입해야 하므로, 아래 add-only 지침의 "최소 연결 훅" 조항이 특히 중요하다.

### 권장 착수 순서

서사 순서와 의존 관계를 함께 고려한 추천 순서다. 최종 순서는 `Developer Request`에서 확정한다.

1. **비트 1 (경고 컷씬)** — 다른 비트와 독립적이고 가장 작다. add-only 워크플로(신규 파일 + 최소 훅 + 리뷰 서브에이전트)를 처음 검증해보기에 적합한 시작점.
2. **비트 2 (정전·변모)** → **비트 3 (구출 서브시퀀스)** → **비트 4 (식탁 인식)** 순서로 진행. 세 비트가 서로 이어지는 한 장면이므로 순서를 바꾸면 앞뒤 맥락이 끊긴다.

## Chapter3 전용 add-only 지침

- 루트 `CLAUDE.md`의 add-only 원칙을 그대로 따른다: 새 로직·화면·테스트는 새 파일로, 기존 파일에는 최소 연결 훅만.
- 새 시퀀스에 필요한 상태는 기존 `FlowState`나 `EpiloguePhase`를 고쳐 쓰지 말고, 별도 상태 타입을 새 파일(예: `shared/wardenWarningLogic.ts`, `shared/blackoutLogic.ts`, `shared/dinnerIllusionLogic.ts` 같은 이름 후보)로 만든다. `MemoryReconstructionGame.ts`에는 새 `Screen` 값 한 개와 그에 대응하는 분기만 추가하는 방식을 우선 검토한다.
- 새 배경·스프라이트 에셋은 `src/features/chapter3/assets/`에 추가한다. 기존 `chapter03-*.png` 파일은 교체하지 않는다.
- 새 대사·카피는 원작 `Story/Chapter03.md`의 어휘와 말투(인물별 존댓말/반말 패턴)를 유지한다.
- `DESIGN.md`에 없는 새 컴포넌트 토큰(예: 정전 연출 색상, 구출 서브시퀀스 UI, 식탁 환상 장면 배색)이 필요하면 구현 전에 `DESIGN.md`를 먼저 갱신하고 `npm run design:lint`를 통과시킨다.
