## 완료된 콘텐츠

### 1. 장치 작동 전 누나의 경고 컷씬

- **원작 대응**: `Story/Chapter03.md` 61~80줄
- **상태**: 완료 · 커밋 `d3c285b`, `dd0d13c`
- **플레이어가 겪는 변화**: 연구 구역에서 처음 기억 재구성 장치에 다가가면, 곧장 퍼즐로 들어가지 않고 외계 누나·영수의 경고 대화(누나 → 영수 → 누나, 3줄)가 먼저 나온다. 배경(연구 구역)과 영수 스프라이트는 그대로 보이고, 하단 대화창에 화자와 대사가 표시된다. 마지막 줄 이후 짧은 페이드를 거쳐 퍼즐로 자연스럽게 이어진다. 같은 플레이 세션 동안 재상호작용(예: 퍼즐 실패 후 재시도)해도 경고는 다시 뜨지 않는다.
- **시각 형식**: 처음에는 화면 전체를 덮는 텍스트 방식으로 만들었다가, 개발자 피드백에 따라 배경을 유지한 채 하단에 대화창을 띄우는 방식으로 다시 만들었고, 이후 Chapter2의 대화창(`dialogueBox.ts`)과 완전히 동일한 시각 형식(테두리 없는 둥근 사각형, 하단 24px 여백 전체 폭, 화자 흰색 bold + 대사 흰색 일반체, 우측 하단 진행 힌트)으로 다시 맞췄다.
- **관련 파일**: `shared/wardenWarningLogic.ts`(신규), `shared/dialogueBox.ts`(신규, Chapter2와 동일 형식), `client/MemoryReconstructionGame.ts`의 `drawWarning()`

### 2. 우주선 정전 · 기억세계 변모 연출

- **원작 대응**: `Story/Chapter03.md` 203~227줄
- **상태**: 완료 · 커밋 `4e97349` (브라우저 실동작 확인은 dev 서버 환경 불안정으로 일부만 완료 — 로컬 `npm run dev` 확인 권장)
- **플레이어가 겪는 변화**: 기억의 방에서 추억 물건 5개를 모두 정리하면, 곧장 letting-go(기억 정리 퀴즈)로 가지 않고 아내·누나·영수의 대치 대화 3줄("우리를 다시 죽이려는 거야?" → "너희는 원래부터 살아 있지 않았어." → "그런 말 하지 마!")과 "우주선 전체의 불이 꺼졌다 / 복도와 조종실에 지구의 풍경이 나타나기 시작했다"는 내레이션 2줄이 이어진다. 대사가 한 줄씩 넘어갈 때마다 화면이 점점 어두워지고(정전 연출), 마지막 줄 이후 페이드를 거쳐 letting-go로 연결된다.
- **시각 형식**: 비트1에서 만든 대화창(`renderDialogueBox`)을 그대로 재사용하고, 그 위에 진행 단계에 비례해 짙어지는 반투명 검은 오버레이만 추가했다. 새 배경 이미지는 만들지 않았다(에이전트가 실제 그림 에셋을 제작할 수 없다는 제약에 따른 결정).
- **관련 파일**: `shared/blackoutLogic.ts`(신규), `client/MemoryReconstructionGame.ts`의 `drawBlackout()`

### 3. 외계 가족 구출 서브시퀀스

- **원작 대응**: `Story/Chapter03.md` 229~236줄
- **상태**: 완료 (브라우저 실동작은 로컬 `npm run dev` 확인 요청)
- **플레이어가 겪는 변화**: 비트2의 정전 연출이 끝나면 letting-go로 곧장 가지 않고, 기억의 방 맵으로 돌아온다. 맵 위에 아버지·어머니·누나 3개의 구출 지점이 표시되고, 각 지점에 다가가 상호작용하면 그 인물의 트라우마 루프를 설명하는 짧은 대화(비트1·2와 동일한 대화창)가 진행되며 "구출됨"으로 표시된다. 3명을 모두 구출해야(순서 무관) letting-go로 넘어갈 수 있는 필수 진행 조건이다.
  - 드라마화 반영: 구출한 인원이 늘수록 화면 암전이 점점 밝아져 "우주선이 안정을 되찾는다"는 것을 환경으로 보여준다. 각 인물을 구출하는 순간에는 빛의 링이 확산되는 짧은 이펙트가 나온다. 3명을 모두 구출하면 곧장 페이드하지 않고 "가족이 다시 모였다..." 라는 여운 대사를 한 번 더 보여준 뒤 페이드를 거쳐 letting-go로 연결된다.
  - 버그 수정: 링 이펙트를 처음엔 목표물의 맵 좌표에 그렸는데, 그 좌표가 하필 대화창 영역 안쪽이라 그린 직후 대화창에 가려 안 보였다. 대화창과 절대 겹치지 않는 화면 상단 고정 위치로 옮겨 해결.
- **시각 형식**: 비트1·2에서 만든 대화창(`renderDialogueBox`)을 그대로 재사용. 새 배경 이미지 없이 마커(원+사각형)로 구출 지점을 표시하고, 암전 오버레이는 구출 진행도에 비례해 밝아진다(비트2의 정전 분위기를 이어받되 정적이지 않게).
- **관련 파일**: `shared/rescueLogic.ts`(신규, `RESCUE_COMPLETE_LINE` 포함), `client/MemoryReconstructionGame.ts`의 `drawRescueTargets()`·`drawRescue()`·`rescueDimAlpha()`

## 갱신 규칙

- 콘텐츠 하나가 구현 완료되고 검증(typecheck/test/build/리뷰)까지 끝나면, "완료된 콘텐츠"에 새 항목을 추가한다.
- 항목은 원작 대응 구간, 상태(커밋 해시 포함), 플레이어가 겪는 변화, 관련 파일 순으로 짧게 쓴다 — 구현 방법의 세부 코드 설명은 `chapter3-architecture.md`에 맡기고 여기서는 반복하지 않는다.
- 같은 콘텐츠를 여러 차례 다시 작업한 경우(연출 방식 재작업 등) 최신 상태만 반영하고, 과거 시행착오는 git 이력에 맡긴다.
