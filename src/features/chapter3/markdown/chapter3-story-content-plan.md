## A. 구현 완료 콘텐츠 (요약)

기존 코드를 그대로 두고 참고만 하는 영역이다. add-only 원칙에 따라 이 섹션의 파일들은 원칙적으로 수정하지 않는다.

- **연구 구역 발견 → 기억 연결 퍼즐 → 각성**: 방향키 탐색으로 장치에 접근하고, 기억 조각(얼굴/버릇/목소리 등)을 올바른 가족에게 연결하는 퀴즈. 실패 시 안정성이 깎이고 3회 실패하면 재시도. 게임 경험은 "정답 매칭형 퀴즈"에 가깝다.
- **짧은 행복 + 이상 징후**: 원작에서는 두 개의 장면(137~154 행복한 시간, 155~201 이상 징후)이지만, 코드는 이를 하나의 상호작용으로 압축했다 — 추억 물건 하나를 주울 때마다 `speaker/memory`(행복한 기억)와 `gapSpeaker/gap`(이상 징후) 대사를 함께 보여준다. 이미 두 사건을 합쳐서 처리하고 있다는 점을 새 콘텐츠 설계 시 참고할 것.
- **마지막 식탁 작별(letting-go)**: 원작 353~419줄의 "가족과의 대화, 작별 인사"가 `LETTING_GO_MEMORIES` 퀴즈의 성공 대사로 이미 반영되어 있다. 예: `bowl` 항목의 "마지막 식탁을 어떻게 맞이할까?"가 원작의 마지막 식탁 장면과 대응한다.
- **누나와의 대화("후회해?") → 고향별 도착 → 경비일지**: `epilogueLogic.ts`가 원작 431~500줄을 거의 그대로 대사 단위로 옮겨 구현했다. 크레딧 이후 확장 대사(`postcredits`)는 원작에 없는 추가 창작 콘텐츠다.

## B. 미구현 콘텐츠 — 이번 보완 대상 (2026-08-10 확정 4개 비트)

비트 1·2·3은 완료되었다. 상세 구현 내용은 [`chapter3-development-log.md`](./chapter3-development-log.md)를 참고하고, 이 문서에는 남은 비트 4의 기획만 유지한다.

### 비트 4 · 마지막 저녁식탁 환상 인식 장면 (원작 237~333줄)

- **서사적 위치**: 비트 3 직후. 이 챕터의 감정적 클라이맥스.
- **중심 게임 경험**: 대화 트리 + 인식 연출. 전투나 조작 스킬이 필요한 장면이 아니라, 플레이어가 대사를 따라가며 "위화감"을 발견하는 서사 중심 장면이다.
  1. 평화로운 가짜 행복 — 식탁에 앉은 가족, 초반에는 편안한 대사.
  2. 위화감의 단서들 — "신혼여행 때 묵었던 방 번호 기억나?"에 아내가 답하지 못함, 아들의 "괜찮아요, 아버지" 반복, 딸의 "아빠가 나를 안 보면 나는 어디에 있어?" 등 이미 `collectionLogic.ts`의 gap 대사로 일부 예고되어 있다.
  3. 결정적 질문 — "당신은 내가 행복하길 바라?" / "그럼 왜 나를 여기 가두려고 해?" 아내가 대답하지 못하는 순간, 음식이 검은 입자로 변하고 벽이 흔들리는 이펙트.
  4. 아이들의 만류("가지 마세요" / "또 우리를 버릴 거야?")와 영수의 대답("너희가 죽었다는 걸 인정하지 못해서 붙잡고 있었다").
- **구현 특이사항**:
  - 이 장면은 **선택지가 없는 고정 대화 시퀀스**로 만들지, 플레이어가 "위화감 단서"를 직접 찾아 지목하는 상호작용형으로 만들지 갈린다. 전자는 구현이 간단하고 몰입감 있는 컷씬에 가깝고, 후자는 `collectionLogic.ts`의 "가까이 가서 E키" 패턴을 재사용할 수 있어 기존 구현과 톤이 일치한다. **결정이 필요한 지점.**
  - 인식 완료 후에는 기존 `letting-go` 화면 진입 지점으로 자연스럽게 연결되어야 한다 (이미 letting-go가 353~419줄을 커버하므로, 비트 4는 그 앞부분의 빈틈만 채우면 된다).

## C. 발견된 추가 후보 (미확정 — 사용자 확인 필요)

2026-08-10 대화에서 확정한 4개 비트 외에, 원작을 훑으며 추가로 발견한 콘텐츠 공백이다. 아직 사용자가 승인하지 않았으므로 백로그에 넣지 않았다.

1. **도입부(1~49줄) · 우주선 정착과 그리움**: 영수가 "이온"이라 불리면서도 "영수"로 남기를 선택하고, 매일 가족사진에 말을 거는 장면. 현재 게임은 이 배경 설명 없이 바로 연구 구역 맵에서 시작한다. 짧은 정적 인트로(스크롤 텍스트나 정지 이미지 + 대사)로 넣을 수 있지만, 챕터 선택 화면과 겹치는 역할이라 우선순위가 낮을 수 있다.
2. **재회 순간의 구체적 대사(97~136줄)**: 현재 `drawAwakening`은 "n번째 용기 개방 · 눈을 떴다"처럼 일반화된 문구만 보여준다. 원작의 "여보?" / "당신… 맞아?" / "왜 이렇게 늙었어?" 같은 구체적 재회 대사는 생략되어 있다. 새 화면을 만들 필요는 없고 기존 `drawAwakening` 함수의 문구만 확장하면 되는데, 이는 **기존 파일 수정**에 해당하므로 add-only 원칙상 별도 확인이 필요하다.
3. **마지막 "사랑해" 대사(421~429줄)**: letting-go 완료 시 원작의 "아빠, 사랑해" / "나도 사랑한다" 대사가 생략되어 있다. 이것도 기존 `lettingGoLogic.ts`의 완료 메시지를 수정해야 하는 영역이라 별도 확인이 필요하다.
